Deliverable 2 - NZ June 2026 Dataset

Source: Inside Airbnb https://insideairbnb.com/get-the-data/

Columns:
For Identifying Each Listing: id, listing_url, name
Data Collection Information: scrape_id, last_searched, last_scrapped, source, calendar_last_scrapped
Listing Descriptions: description, neighborhood_overview, picture_url, property_type, room_type
Information About The Host: A range of columns that begin with host, used for identifying the host, their url link, their names and locations
Location Information: neighbourhood, latitude, longitutde, region_id, region_name
Information About The Property: accommodates, bathrooms, bathrooms_text, bedrooms, beds, amenities
Price Information: price, price_quote_checkin_date, price_quote_checkout_date, price_quote_total_price, price_quote_price_per_night, price_quote_raw
Property Stay Rules: A range of different columns beginning with minimum_nights and maximum_nights
Availability: has_availability, availability_30, availability_60, availability_90, availability_365, availability_eoy
Review Information: number_of_reviews, first_review, last_review, review_scores_*, reviews_per_month
Estimated Listing Performance: estimated_occupancy_1365d, estimated_revenue_1365d
License Information: requires_license, license, instant_bookable
Host Portfolio Information: host_listings_count, host_total_listings_count, calculated_host_listings_count_* fields
